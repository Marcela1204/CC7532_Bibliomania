Dicas de Uso
  • Deixe os campos de data em branco para incluir todos os empréstimos
  • Se preencher apenas a Data Inicial, serão inclusos empréstimos a partir dessa data
  • Se preencher apenas a Data Final, serão inclusos empréstimos até essa data
  • Se preencher ambas as datas, elas devem formar um período válido (data final ≥ data inicial)
  • Selecione um status para filtrar por tipo específico
  • O arquivo CSV será gerado com as colunas: ID, Leitor, Email, Telefone, Livro, Autores, ISBN, Data Empréstimo, Data Devolução, Data Limite, Status, Renovações e Multa
  • Use um aplicativo de planilha (Excel, LibreOffice, Google Sheets) para abrir o arquivo CSV
Sobre

Utilize este formulário para gerar relatórios de empréstimos em formato CSV. Você pode filtrar os dados por um intervalo de datas e pelo status do empréstimo.

O relatório inclui informações detalhadas do leitor, do livro emprestado, datas importantes e eventuais multas por atraso.

Validação

Período Válido: A data final não pode ser anterior à data inicial.
